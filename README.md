# ロト6・ロト7 AI Engine Ver.4.0

## 内蔵データ
- ロト6：第1回～第2122回（2026/7/23）
- ロト7：第1回～第687回（2026/7/24）

## 機能
- ロト6・ロト7切替
- 直近10/30/100回・全期間分析
- 数字ランキング、間隔、平均合計、平均奇数数
- 次回5セット生成
- 購入セット保存、抽選結果照合、検証履歴
- 過去履歴検索
- JSONバックアップ
- PWA・オフライン対応

## Vercel公開
1. ZIPを展開
2. GitHubで新規リポジトリを作成
3. 展開した全ファイルをアップロード
4. Vercelで Add New → Project → 対象リポジトリをImport
5. Framework Presetは Other、Build Commandは空欄、Output Directoryは空欄のままDeploy

公開後にVercelのURLが発行されます。
