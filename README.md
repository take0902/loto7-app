# ロト6・ロト7 AI Engine Ver.2.1

## 追加内容
- ロト6とロト7を同じアプリに統合
- 画面上部でロト6／ロト7を切替
- 予想5セット、検証履歴、ランキング、特徴量設定をゲーム別に保存
- ロト7は1～37から7数字、ボーナス2数字に対応
- 両方のデータをまとめてJSONバックアップ可能

## 注意
ロト7の初期スコアは均等値から開始します。抽選結果を入力するたび、直近履歴が蓄積されスコアへ反映されます。

## 設置方法
`index.html` を既存アプリのファイルと置き換えてください。GitHubとVercelを連携している場合、GitHub保存後に自動反映されます。
