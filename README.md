# ロト6 AI Engine Ver.2.0

## 使用方法
1. `index.html` をSafariで開く
2. 「次回予想」で5セット生成
3. 購入時に「今回の購入セットとして保存」
4. 抽選後に「検証」から本数字・ボーナスを入力

## Vercel / GitHub Pages
このフォルダの `index.html` をルートに配置するだけで公開できます。

## Ver.2.0 の主な機能
- 次回5セット自動生成
- 購入セット保存
- 抽選結果との一致数検証
- 前回重複、±1、ボーナス隣接、合計、偶奇、AC値の記録
- 1～43ランキング
- 特徴量重み調整
- JSONバックアップ／復元
- 端末内保存・オフライン動作

注意：本アプリは研究・記録用です。各組み合わせの1等確率は同一であり、当選を保証しません。
