AI Lottery Lab Ver.26.0 フルセット更新

【更新方法】
1. このZIPをiPhoneの「ファイル」で展開します。
2. GitHubの take0902/loto7-app を開きます。
3. Add file → Upload files を選びます。
4. 展開したフォルダ内の全ファイルを選択してアップロードします。
5. Commit changes を押します。
6. Vercel反映後、Safariを完全に閉じて開き直します。

【重要】
・コードを開く必要はありません。
・GitHubにある loto6.json と loto7.json は削除しないでください。ZIPには収録していません。
・端末内の購入履歴・第688回検証結果はlocalStorageに残るため維持されます。
