AI Lottery Lab Ver.23.0 フルセット更新

【重要】
このZIPには画面・CSS・JavaScript・PWA・Vercel設定など、更新に必要なプログラムファイルをすべて収録しています。
既存の loto6.json と loto7.json は全履歴データのため、GitHub上にあるものをそのまま保持してください。ZIPには誤って履歴を消さないため含めていません。

更新方法
1. ZIPを展開
2. GitHubの loto7-app → Add file → Upload files
3. 展開したファイルをすべて選択
4. Commit changes
5. Vercel反映後、Safariを完全に閉じて再度開く
6. 表示が古い場合はSafariの再読み込みを長押しして更新

収録ファイル
index.html / app.css / style.css / app.js / latest.json / manifest.webmanifest / manifest.json / icon.svg / service-worker.js / vercel.json

履歴データ
