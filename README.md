# ロト6・ロト7 AI Engine Ver.9.0

## 主な追加
- ロジック重み最適化
- Hot、Gap、安定性、直前回重複の配分を候補比較
- 訓練期間と検証期間を分離
- 検証データを最適化に使わないホールドアウト方式
- 訓練・検証成績の比較
- 過学習チェック
- 推奨重みをバランス戦略へ適用
- ロト6／ロト7ごとに重みを個別保存
- 標準重みへのリセット

## 重要
これはブラウザ内で行う統計的な重み探索です。ニューラルネットワーク等の機械学習モデルではありません。
過去データへの適合度を比較する機能であり、将来の当選を保証しません。
