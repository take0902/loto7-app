AI Lottery Lab Ver.21.1.2 API 404修正版

今回の原因:
api/latest.js がGitHubの api フォルダに入らず、VercelにAPIが作成されていませんでした。
画面の 404 はアプリ処理ではなく、API URL自体が存在しない意味です。

更新方法:
1. ZIPを展開します。
2. GitHubの loto7-app で Add file → Upload files を開きます。
3. 次の2ファイルを選択してアップロードします。
   ・api-latest.js
   ・vercel.json
4. Commit changes を押します。
5. Vercel反映後、Safariでアプリを再読み込みします。
6. 「ロト6・ロト7の最新データを確認」を押します。

重要:
フォルダはありません。2ファイルともリポジトリ直下へアップロードしてください。
app.jsのコード編集は不要です。
