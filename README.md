# AI Lottery Lab Professional 2.0.0

ロト6・ロト7の統計分析、購入履歴、公式抽選結果との照合を行うiPhone対応Webアプリです。

## 2.0.0の重点修正
- 旧版の手動抽選キャッシュを廃止し、予想対象回が抽選結果へ混入する不具合を解消
- 公式確認済みデータだけを自動当選判定に使用
- 保存した購入回号と公式抽選回号が一致しない場合は検証を停止
- ロト6・ロト7の等級判定を固定テスト
- 壊れていたアプリ本体の自動更新画面を撤去
- 古いService Workerとキャッシュを起動時に解除
- 全画面のバージョンをProfessional 2.0.0へ統一

日々の抽選結果は `api/latest.js` がみずほ銀行公式CSVを確認します。
